# Agent rules

See [CLAUDE.md](CLAUDE.md). Same rules apply: no co-author trailers, no
model names in PR title/body, `feat/|fix/|chore/|docs/|test/` branches,
biome + strict TS, tests with code, docs in the same PR, rebuild both
dist bundles (`pnpm build`) and smoke-run before push when `src/` changed.
